MiniShop — исходный проект для проверочной работы № 2 (занятия 29–32)

Откройте index.html в браузере. Для редактирования используйте редактор кода.

Состав проекта:
- index.html — готовая базовая разметка MiniShop из первой проверочной;
- style.css — базовое оформление шапки, шести карточек и подвала.

ЧТО УЖЕ СДЕЛАНО:
- логотип и четыре ссылки меню;
- шесть товаров с названиями, ценами и кнопками;
- сетка карточек Grid и шапка Flexbox;
- простое оформление и hover для кнопок.

ЧТО НУЖНО СДЕЛАТЬ САМОСТОЯТЕЛЬНО:
- три смысловые колонки: категории / каталог / акции;
- свойства продвинутого Flexbox;
- transform, transition, :active и анимация @keyframes;
- адаптивность и мобильное меню;
- CSS-переменные и их переопределение.

В проекте вместо фотографий используются символы-заглушки, поэтому он
открывается без интернета и дополнительных файлов. При желании можно
заменить их на изображения из своей первой проверочной работы.

Внимание: кнопки «В корзину» демонстрационные; JavaScript не требуется.
